# 2025 서울 상권 유동인구 대비 매출성과 분석

서울시 상권분석 데이터를 기반으로 2025년 상권별 매출성과를 비교하고, 성과 차이가 거래 발생 강도·평균 결제금액·점포 규모·업종 구성·입지 특성과 어떤 관계를 보이는지 분석한 프로젝트입니다.

단순한 상권 순위 산출에 그치지 않고, Open API 수집부터 GCS·BigQuery 적재, dbt 모델링, Python 분석, Looker Studio 대시보드까지 하나의 데이터 분석 파이프라인으로 구성했습니다.

> 이 프로젝트의 `매출/유동인구`와 `거래건수/유동인구`는 실제 방문자의 구매전환율이 아닙니다. 추정매출과 측정 유동인구를 이용한 상대적 성과·거래 발생 강도 지표로 해석합니다.

**빠른 결과 보기:** [Looker Studio 대시보드](https://datastudio.google.com/reporting/d8b2094c-6cb4-46ab-b319-6d493e19e47f) · [포트폴리오용 요약 노트북](../notebooks/seoul_commercial_portfolio.ipynb) · [전체 분석 노트북](../notebooks/seoul_commercial_analysis.ipynb)

## 프로젝트 목표

1. 2025년 유동인구 대비 매출성과가 높은 상권과 낮은 상권은 어디인가?
2. 성과 차이는 거래 발생 강도와 평균 결제금액 중 무엇과 더 관련되어 있는가?
3. 고성과·저성과 상권은 점포, 직장인구, 집객시설 및 면적에서 어떤 차이를 보이는가?
4. 업종 수와 업종별 매출 집중도는 성과와 어떤 관계를 보이는가?
5. 자치구·행정동 및 주변 상권의 공간적 특성도 성과 차이와 관련되어 있는가?

### 원본 데이터 수집 및 수동 적재 절차

원본 데이터의 수집과 클라우드 적재는 다음 순서로 진행했습니다.

1. Python으로 서울 열린데이터광장 Open API를 호출해 데이터별 CSV 파일을 생성했습니다.
2. Google Cloud Console에서 CSV 파일을 `codeit-data15-practice-dion` 버킷의 `seoul_commercial/raw/` 경로에 직접 업로드했습니다.
3. BigQuery 콘솔의 **테이블 만들기** 기능에서 GCS의 CSV 파일을 원본으로 지정했습니다.
4. `seoul_commercial_raw` 데이터셋에 데이터별 Raw 테이블을 생성했습니다.
5. 테이블별 행 수, 분석기간, 주요 키 및 결측 여부를 SQL로 확인했습니다.

GCS 업로드와 BigQuery Raw 테이블 생성은 별도의 배치 프로그램이 아닌 Google Cloud Console에서 수행한 수동 적재 과정입니다. 이후 정제·조인·집계 과정은 dbt staging/mart 모델로 관리했습니다.

## 핵심 지표

### 유동인구 대비 매출성과

```text
sales_per_flow = 연간 총매출 ÷ 연간 총유동인구
```

방문자 1인당 실제 매출이 아니라, 측정 유동인구 대비 상대적인 매출성과입니다.

### 성과 분해

```text
유동인구 대비 매출
= 유동인구 대비 거래건수 × 평균 결제금액
```

```text
transactions_per_flow = 총매출건수 ÷ 총유동인구
average_transaction_value = 총매출 ÷ 총매출건수
```

이를 통해 성과 차이가 거래 발생 강도와 평균 결제금액 중 어느 쪽과 더 관련되는지 확인했습니다.

### 업종 집중도

상권별 업종 매출 비중을 이용해 HHI를 계산했습니다.

```text
HHI = Σ(업종별 매출 비중²)
```

- HHI가 낮을수록 여러 업종에 매출이 분산
- HHI가 높을수록 특정 업종에 매출이 집중
- 업종 수와 HHI는 `stg_sales`에 매출 행이 존재하는 업종 기준

## 핵심 분석 결과

### 1. 전체 Top 5는 시장·도매형 상권

| 순위 | 상권 | 상권 유형 | 매출/유동인구 |
|---:|---|---|---:|
| 1 | 가락시장 | 발달상권 | 14,064,348 |
| 2 | 강서농산물도매시장 | 발달상권 | 9,947,162 |
| 3 | 동서시장 | 전통시장 | 1,940,637 |
| 4 | 경동시장 | 전통시장 | 1,811,699 |
| 5 | 인왕시장(홍제골목형상점가) | 전통시장 | 1,281,692 |

Top 5는 측정 유동인구에 비해 총매출과 거래건수가 매우 큰 시장·도매형 상권이었습니다. 도매 거래와 매출·유동인구 데이터의 포착 범위 차이가 높은 비율에 영향을 줬을 가능성이 있으므로 이를 실제 구매전환율로 해석하지 않았습니다.

### 2. 성과 차이는 객단가보다 거래 발생 강도와 더 밀접

Top 5와 Bottom 5의 차이는 평균 결제금액보다 `거래건수/유동인구`에서 훨씬 크게 나타났습니다. 전체 1,558개 상권에서도 유동인구 대비 매출성과는 다음 변수와 양의 관계를 보였습니다.

| 변수 | Spearman ρ |
|---|---:|
| 총매출건수 | 0.673 |
| 평균 점포 수 | 0.567 |
| 매출 업종 수 | 0.498 |
| 집객시설 수 | 0.410 |
| 직장인구 | 0.387 |

이는 인과효과가 아니라 변수 사이의 단조 연관성을 나타냅니다.

### 3. 강남 마이스는 다업종 분산형 고성과 상권

- 관광특구 중 유동인구 대비 매출성과 1위
- 다업종 분산형 상권 중 유동인구 대비 매출성과 1위
- 유동인구 대비 거래건수: 30.32
- 매출 데이터에 나타난 업종 수: 30개
- 1위 업종 매출 비중: 21.2%
- 업종 매출 HHI: 0.093
- 네 분기 모두 서울 전체 상위권 유지

특정 업종에 매출이 집중된 시장형 Top 상권과 달리, 강남 마이스는 높은 거래 발생 강도와 낮은 업종 집중도가 함께 나타난 사례였습니다.

### 4. 단순한 주변 상권 수는 성과를 설명하지 못함

X·Y 좌표를 이용해 500m·1km 반경의 주변 상권 특성을 계산했습니다.

| 공간 변수 | 유동인구 대비 매출성과와의 Spearman ρ |
|---|---:|
| 500m 이내 상권 수 | 0.029 |
| 1km 이내 상권 수 | -0.048 |
| 500m 이웃의 평균 성과 | 0.157 |
| 500m 이웃의 평균 직장인구 | 0.130 |

동대문·동묘·청량리에서는 상권 밀집이 확인됐지만, 주변 상권이 많다는 사실만으로 개별 상권의 성과가 높아지지는 않았습니다. 현재 데이터에서는 위치 자체보다 점포 수, 거래건수, 업종 구성 등 상권 내부 구조가 성과와 더 밀접하게 연결됐습니다.

## 공간 패턴 분석의 범위

High–High, Low–Low, High–Low, Low–High는 각 상권과 1km 이내 주변 상권의 성과를 서울 전체 중앙값과 비교한 탐색적 분류입니다.

- 통계적 유의성 검정을 포함한 Local Moran’s I 결과가 아님
- 정식 공간 군집이 아니라 후속 지도 검토 대상 후보
- 위치가 매출에 미치는 인과효과를 의미하지 않음
- 좌표 기반 거리는 상권 중심점 사이의 직선거리

## 분석 한계

- 유동인구는 고유 방문자 수가 아닌 추정 유동량입니다.
- 매출건수는 고유 구매자 수가 아니므로 실제 구매전환율을 계산할 수 없습니다.
- 추정매출과 유동인구의 공간·업종 포착 범위가 다를 수 있습니다.
- 상권 간 중심점 거리는 실제 도로망 기반 보행거리가 아닙니다.
- 업종 수와 집중도는 매출 데이터에 나타난 업종만을 기준으로 합니다.
- 공간분석은 탐색적 연관성 분석이며 입지의 인과효과를 증명하지 않습니다.
